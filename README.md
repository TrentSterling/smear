## Proposed game roadmap after V34

This is a design draft; the first two milestones have been implemented in V35 and V36. The working direction is a freeform 3D interactive-buddy sandbox with optional stunt challenges. The aim is a room where the player can arrange an experiment, get a surprising physical reaction, change one thing, and immediately try again. Version ranges below describe an order, not release promises.

The audited starting point is V34, commit `a476f02496f12264a0f3aac50823e572880f02a0`. Its release evidence is in [props-v34.json](docs/qa/props-v34.json). It already has GPU dismemberment, finite bleeding, a spiked bat, grenades, painted breakable crates, explosive barrel chains, LTC lighting, and persistent liquid. Source inspection shows two important limits: `rigBroken()` prevents recovery after any joint separates, and `buildProps()` creates six static breakables. V35 implements selected-buddy restoration and dummy placement. V36 adds moving and placing props with attached paint. Personality, stunt challenges and player-facing replay remain future work.
